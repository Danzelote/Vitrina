# Atajos de teclado

En la Vitrina, la tecla **H** muestra esta lista en pantalla.

| Tecla | Qué hace |
|---|---|
| **P** | Empieza la presentación (o sale de ella). En el visor, empieza desde esa foto |
| **← →** | Foto anterior o siguiente |
| **Espacio** | Pausa o sigue el video |
| **Esc** | Volver |
| **1 2 3 4** | Años, Meses, Fotos, Colecciones |
| **+ −** | Acercar o alejar la cuadrícula |
| **B · W · A** | Apariencia: oscuro (*black*), claro (*white*) o automático |
| **K** | Ken Burns: apagado → solo zoom → zoom y paneo |
| **R** | Reloj: oculto → 12 h → 24 h |
| **I** | Fecha y lugar sí/no |
| **M** | Un día como hoy (*memories*) sí/no |
| **S** | Orden aleatorio (*shuffle*) sí/no |
| **L** | Brillo automático (*light*) sí/no |
| **N** | Modo noche ahora (otra vez N para salir) |
| **E** | Español o inglés |
| **,** | Abre o cierra Ajustes (como ⌘, en la Mac) |
| **H** | Esta lista |

Las teclas de volumen y brillo de la Mac también funcionan. La tecla de encendido pregunta si quieres reposo, apagar o reiniciar.
