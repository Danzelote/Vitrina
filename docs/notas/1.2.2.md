## Vitrina 1.2.2 · menos trabajo para el núcleo

- El servidor gráfico copia cada cuadro a la pantalla en vez de intercambiar pantallas. Con las GeForce viejas (controlador nouveau), cada intercambio dejaba al núcleo esperando sin dormir: casi 1 % de procesador por cuadro.
- **Reinicia la Mac una vez después de actualizar** (Ajustes → Apagar… → Reiniciar) para que tome efecto.
- El diagnóstico muestra lo que reporta el servidor gráfico, para confirmarlo.
